# West Metro Badminton Website

Official website for West Metro Badminton, a community badminton program offering open gym and structured training opportunities in the west metro area of Minnesota.
www.westmetrobadminton.com

## About West Metro Badminton

West Metro Badminton provides a welcoming environment for players of all ages and skill levels to learn, play, and improve through badminton.

Programs include:

- Community Open Gym
- Structured Training Sessions
- Skill Development Opportunities
- Recreational and Competitive Play

Sessions are held at Wayzata High School and are independently organized by West Metro Badminton.

## Website Features

- Program information
- Schedule and session details

## Local Development

Clone the repository:

```bash
git clone <repository-url>
cd west-metro-badminton
```

Open `index.html` in your browser or run a local development server.

Example using Python:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```

## Program Information

### Location

Wayzata High School  
Gyms 7 & 8

### Arrival Instructions

Enter through the Athletics Entrance located at the back of the school.

From the entrance:

1. Follow signs toward Gyms 7 & 8.
2. Turn right after entering.
3. Walk through the cafeteria.
4. Take the door on the left.
5. Continue past the weight room.
6. Gyms 7 & 8 will be on your right.

## Important Note

West Metro Badminton is an independently organized community badminton program and is not an official Wayzata High School athletics activity.
